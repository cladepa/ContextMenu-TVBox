# ContextMenu-TVBox

Кастомное контекстное меню (ПКМ-замена) для Android TV box без физической правой кнопки
на пульте-аэромыши. Root-based, собирается вручную через aapt/javac/dalvik-exchange
(minSdk 23, только API 23 android.jar доступен на сборочной машине — без лямбд,
без androidx).

Полная история разработки — в диалоге с Claude.
